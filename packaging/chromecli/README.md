# truefrontier-chromecli

An alias package (not published yet): installing it installs [**truefrontier-webcli**](https://pypi.org/project/truefrontier-webcli/),
which provides the `chromecli` command and its `chromecli-host` native messaging host. The Chrome extension lives in the
repo's `extensions/chromecli/` (Load unpacked). See `docs/chromecli.md` in the [webcli repo](https://github.com/truefrontier/webcli).
