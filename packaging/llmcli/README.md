# llmcli

Installing this package installs [**webcli**](https://pypi.org/project/webcli/), which provides the `llmcli` command — agent-native CLIs for chat AIs (Gemini, ChatGPT, and Meta's Muse) over your own signed-in, hidden Chrome sessions.

```sh
pip install llmcli     # equivalent to: pip install webcli
```

After install, both `llmcli` and `webcli` are on your path. See the [webcli project page](https://github.com/truefrontier/webcli) for usage, sign-in, exit codes, and the security model.
