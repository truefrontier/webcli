Jev element finder

Optional. With your TypeSafe key, chromecli asks Jev to find the element an agent describes (chromecli find, --find) and to classify what a click does. Jev can only add confirm prompts, never remove one.

Your Share-act tabs ask only if Jev is ≥ risk floor sure a click is risky; agent-opened tabs ask unless it's ≥ confidence floor sure it's safe.

The key stays in this browser (chrome.storage.local). Only chromecli's service worker sends it, and only to api.typesafe.ai. It never goes to the chromecli command, its logs, or web pages; chromecli status shows only jevConfigured. Jev sees element names and labels, never field values. Saving asks Chrome for access to https://api.typesafe.ai/*.
